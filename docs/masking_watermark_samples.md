# 手机号打码 · 导出审批 · 文件水印 样本（全虚构）

## 一、手机号打码规则与样本

规则：手机号默认打码，保留**后 4 位**，前段以 `****` 显示；明文查看需更高权限且留痕；打码后仍可能被关联重识别，不可当作彻底匿名。

| 场景 | 展示值（虚构） | 说明 |
|---|---|---|
| 列表默认展示 | `****5678` | 仅后 4 位可见 |
| 无手机号 | `—` | 不占位、不编造 |
| 明文查看 | 需二次授权 + 审计记录 | 记录操作人/时间/对象/理由 |

## 三、导出文件水印样本（虚构）

导出文件每页带水印，含以下字段（具体字段清单需按客户标定）：

```
导出人: op_007    导出时间: 2026-11-20T10:35Z    审批单: EXP-20261120-007
范围: org_fict_001/site_fict_001    用途: 季度会员结构复盘（虚构）
文件序列: SN-FICT-000017    页码: 3 / 12
```

**水印 ≠ 访问控制**：水印用于事后追溯泄露源，不能替代审批与权限；手机号即使打码仍可能关联重识别。
