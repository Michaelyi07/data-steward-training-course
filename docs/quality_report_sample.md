## 五、读报告的正确姿势（讲师要点）
1. 先确认分母：是否排除了软删行；不同对象分母不可混用。
2. 再看趋势：单期数值不如连续几期变化有意义。
3. 阈值是告警线不是判决线：触发后由人核查，不得自动改主数据。
4. 三率不是互斥分类，不要把三者相加求"健康度"。
